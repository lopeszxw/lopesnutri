# Diretrizes do Projeto LopesNutri

## Sincronização Automática com GitHub
- **Repositório**: `https://github.com/lopeszxw/lopesnutri.git` (branch: `main`)
- **Regra**: Sempre que qualquer arquivo for criado, modificado ou deletado no projeto local através de prompts/comandos, realizar automaticamente o `git add`, `git commit` com mensagem descritiva e `git push origin main`.
- **Notificação**: Sempre avisar ao usuário na resposta final que as mudanças foram sincronizadas e enviadas para o GitHub, incluindo detalhes do commit.
